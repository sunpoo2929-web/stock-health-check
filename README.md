# 🩺 7 PM Stock Health Check

ทุกวันทำการ 19:00 น. ระบบจะ:
1. ดึงราคาปิดของหุ้น 20 ตัวในลิสต์ แล้วคำนวณ **CDC Action Zone V3, RSI และ Trend**
2. **ส่งแจ้งเตือนเข้า iPhone** (ผ่านแอป ntfy) เฉพาะวันที่มีเรื่องสำคัญ แตะแล้วเปิด Dashboard
3. **อัปเดต Dashboard** ที่เปิดจากไอคอนบนหน้าโฮม iPhone ได้เหมือนแอป

ฟรีทั้งหมด ไม่ต้องเปิดคอมทิ้งไว้ ใช้เวลาติดตั้งประมาณ 20 นาที

---

## ติดตั้งทีละขั้น

### ขั้นที่ 1 · ติดตั้งแอปแจ้งเตือน ntfy บน iPhone (3 นาที)
ntfy เป็นแอปรับแจ้งเตือนฟรี **ไม่ต้องสมัครสมาชิก ไม่ต้องใส่อีเมลหรือเบอร์โทร**

1. เปิด App Store ค้นหา **ntfy** ติดตั้ง แล้วกด **อนุญาตการแจ้งเตือน**
2. ในแอปกดปุ่ม **+** (Subscribe to topic)
3. ช่อง Topic ใส่ชื่อที่เดายาก เช่น **`hc-616d28ff77`** (ใช้ชื่อนี้ หรือตั้งเองก็ได้ ใช้ a–z, 0–9 และขีด -)
4. กด Subscribe

> ใครรู้ชื่อ topic ก็อ่านแจ้งเตือนได้ จึงควรใช้ชื่อที่สุ่มแบบด้านบน ห้ามใช้ชื่อง่าย ๆ อย่าง `stock`

### ขั้นที่ 2 · สร้างบัญชีและ repository บน GitHub (5 นาที)
1. สมัครที่ github.com (ฟรี)
2. มุมขวาบน กด **+** → **New repository**
   - Repository name: `stock-health-check`
   - เลือก **Public**
   - กด **Create repository**
3. ในหน้า repo ที่ว่างอยู่ กดลิงก์ **uploading an existing file**
4. แตกไฟล์ zip ที่ได้ แล้วลาก **ไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์ `stock-health-check`** ไปวาง แล้วกด **Commit changes**

> ⚠️ โฟลเดอร์ `.github` เป็นโฟลเดอร์ซ่อน บน Mac กด `Cmd + Shift + .` ใน Finder เพื่อให้เห็น
> ถ้าอัปโหลดแล้วไม่มีโฟลเดอร์ `.github` ใน repo ให้กด **Add file → Create new file**
> ตั้งชื่อ `.github/workflows/health-check.yml` แล้ววางเนื้อหาจากไฟล์นั้นลงไป แล้วกด Commit

### ขั้นที่ 3 · ใส่ชื่อ topic ของ ntfy (2 นาที)
1. ใน repo ไปที่ **Settings → Secrets and variables → Actions**
2. กด **New repository secret**
   - Name: `NTFY_TOPIC`
   - Secret: ชื่อ topic จากขั้นที่ 1 (เช่น `hc-616d28ff77`)
3. กด **Add secret**

### ขั้นที่ 4 · เปิดหน้า Dashboard (2 นาที)
1. **Settings → Pages**
2. Source: **Deploy from a branch** · Branch: **main** · โฟลเดอร์: **/docs** → กด **Save**
3. รอ 1–2 นาที ด้านบนจะขึ้นลิงก์ `https://<ชื่อผู้ใช้>.github.io/stock-health-check/`

### ขั้นที่ 5 · ทดสอบครั้งแรก (3 นาที)
1. แท็บ **Actions** → ถ้ามีปุ่มให้เปิดใช้ ให้กด **I understand… enable them**
2. ด้านซ้ายเลือก **7 PM Stock Health Check** → **Run workflow** → **Run workflow**
3. รอ 1–3 นาทีจนขึ้นเครื่องหมาย ✅ → iPhone จะได้แจ้งเตือนจาก ntfy
4. ถ้าขึ้น ❌ ให้ไปที่ **Settings → Actions → General → Workflow permissions** เลือก **Read and write permissions** → Save แล้วรันใหม่

> กดรันเองจะใช้ราคาปิดล่าสุดที่มี จึงทดสอบได้แม้เป็นวันเสาร์-อาทิตย์

### ขั้นที่ 6 · เพิ่ม Dashboard ไว้บนหน้าโฮม iPhone (1 นาที)
1. เปิดลิงก์จากขั้นที่ 4 ใน **Safari**
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**
3. จะได้ไอคอน **Health Check** เปิดเต็มจอเหมือนแอป

เสร็จแล้ว จากนี้ระบบรันเองทุกวันจันทร์–ศุกร์ 19:00 น.

## อ่าน Dashboard อย่างไร
- **บรรทัดใหญ่ด้านบน:** วันนี้ต้องทำอะไรไหม (ต้องดู N ตัว / จังหวะสะสม / ไม่ต้องทำอะไร)
- **ตาราง 20 ช่อง:** สีของแต่ละช่อง = โซน CDC วันนี้ ช่องที่มีกรอบขาว = ต้องดูวันนี้ แตะช่องเพื่อดูกราฟ
- **สถานะ CDC:** นับจำนวนตามสถานะครบ 10 แบบ แตะสถานะไหนก็กรองเหลือเฉพาะตัวที่อยู่ในสถานะนั้น
- **ทุกตัว:** แถบสีเล็กใต้ชื่อ = โซน CDC ย้อนหลัง 20 วัน

| สถานะ | ความหมาย |
|---|---|
| Buy Alert / Sell Alert | วันนี้เพิ่งเปลี่ยนเป็นเขียว / แดง (สัญญาณใหม่) |
| is Bullish / is Bearish | เส้น Fast (EMA12) อยู่เหนือ / ใต้ เส้น Slow (EMA26) |
| Green | Bullish และราคาอยู่เหนือ Fast — ขาขึ้นเต็มตัว |
| Yellow (Dip) | Bullish แต่ราคาย่อลงใต้ Fast — ย่อตัวในขาขึ้น |
| Orange (Strong Dip) | Bullish แต่ราคาย่อลงใต้ทั้ง Fast และ Slow — ย่อแรง |
| Red | Bearish และราคาอยู่ใต้ Fast — ขาลงเต็มตัว |
| Light Blue (Rally) | Bearish แต่ราคาเด้งขึ้นเหนือ Fast — เด้งในขาลง |
| Blue (Strong Rally) | Bearish แต่ราคาเด้งเหนือทั้ง Fast และ Slow — เด้งแรง ใกล้กลับตัว |

## กฎการแจ้งเตือน (ตั้งไว้สำหรับ "ถืออยู่และอยากสะสมเพิ่ม")

| ระดับ | เหตุการณ์ |
|---|---|
| 🚨 ต้องดู | 🔴 CDC Buy → Sell · 📉 Trend เปลี่ยนเป็นขาลง · ⚡ ราคาลง ≥ 3% (ดัชนี ≥ 2%) |
| 🟢 จังหวะสะสม | 🟢 CDC Sell → Buy · 🟡🟠 ย่อตัวในขาขึ้น (เพิ่งเข้าโซนเหลือง/ส้ม) · 🧊 RSI ลงต่ำกว่า 30 |
| ℹ️ ข้อมูลประกอบ | 🌡️ RSI เกิน 70 (ไม่ควรไล่ซื้อ) · 📈 กลับเป็นขาขึ้น · ⚠️ หลุดขาขึ้น |

ระบบแจ้งเฉพาะวันที่สถานะ **เปลี่ยน** ไม่แจ้งซ้ำทุกวัน
ถ้าอยากตั้ง Buy Zone ให้ตัวไหน เพิ่ม `buy_zone: [ต่ำ, สูง]` ใน `watchlist.yaml`

## แก้รายชื่อหุ้น / เกณฑ์
ใน GitHub เปิดไฟล์ `watchlist.yaml` → กดไอคอนดินสอ → แก้ → Commit changes
- **เพิ่มหุ้นไทย:** `- {symbol: CPALL, name: ซีพี ออลล์, group: th, status: accumulate}`
- **เพิ่ม DR:** ระบุหุ้นแม่ เช่น `- {symbol: AAPL80, name: Apple, group: dr, status: accumulate, underlying: AAPL}`

## ข้อมูลและข้อจำกัด
- **แหล่งราคา:** Yahoo Finance เป็นหลัก ดัชนี SET ดึงจาก set.or.th (Yahoo ไม่มีราคาย้อนหลังของดัชนี SET) ถ้า Yahoo ล่ม หุ้นไทยจะสลับไปใช้ set.or.th เอง
- **ดัชนี SET มีเฉพาะราคาปิด:** CDC จึงคำนวณจากราคาปิด สีจะใกล้เคียง TradingView แต่บางครั้งวันเปลี่ยนสีอาจคลาดกัน 1 วัน
- **DR คำนวณจากหุ้นแม่:** NVDA, AMD, GOOG, TSLA ใช้ราคาปิดของคืนก่อน (ตลาดสหรัฐฯ ปิดตอนเช้าเวลาไทย) ส่วน TAIWAN19 ใช้ 0050.TW ซึ่งมีราคาปิดของวันนั้นแล้ว ถ้าตลาดต่างประเทศหยุดและไม่มีแท่งใหม่ ระบบจะไม่แจ้งซ้ำ
- **วันหยุดตลาดไทย:** ระบบตรวจเองและข้ามไป ถ้า 19:00 ยังไม่มีราคาปิด จะรอซ้ำทุก 10 นาที นานสุด 40 นาที
- **เวลา:** GitHub อาจรันช้ากว่ากำหนด 5–15 นาที
- **หน้า Dashboard เป็นสาธารณะ:** คนที่มีลิงก์จะเห็นรายชื่อหุ้นและค่า indicator (ไม่มีข้อมูลจำนวนหุ้นหรือเงิน)
- ระบบช่วยคัดกรอง ไม่ใช่คำแนะนำการลงทุน
